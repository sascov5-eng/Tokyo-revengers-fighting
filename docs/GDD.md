# GDD — Tokyo Revengers Fighting v0.2

Короткая уличная 1на1 на вертикальном iPhone. Два бойца, CPU, 99 секунд, сенсор. Ощущение Java-мода, вселенная «Токийских мстителей».

## Столпы
- Вес удара важнее комбо-листа.
- Персонажи отличаются телом и одним козырем.
- Сессия короткая: выбрал → подрался → реванш.
- Вертикаль: камера не ездит, арена целиком на экране.

## Не делаем
Онлайн, второй игрок на экране, сюжет-арку, оружие, глубину сцены, App Store, третьего персонажа.

## Бой
- Одна полоска HP, таймер 99 сек. Кто жив к нулю таймера — выиграл. Одинаковое HP — ничья.
- Действия: ходьба, короткий прыжок, блок, рука, нога, спец.
- Блок режет урон, не даёт неуязвимость. Чип урона ~25%.
- Спец: кулдаун ~2 сек, не убивает через пол-экрана.

## Управление
Лево снизу — стик X. Право снизу — прыжок, блок, рука, нога, спец.

## Персонажи

| | Такемичи | Майки |
|---|---|---|
| Роль | танк / сброс | спид / кик |
| HP | выше | ниже |
| Скорость | ниже | выше |
| Рука | слабая | средняя |
| Нога | средняя | сильная |
| Спец | Time Leap: короткие i-frames + шаг назад + чуть HP | Kick Combo: рывок-кик |

Цифры баланса точные появятся в фазе 2, не сейчас.

## Петля
меню → выбор персонажа → бой 99 сек → KO/таймер → реванш или в меню. В настройках — звук вкл/выкл.

## Арена среза 0
Одна: ночная улица Toman. Без разрушений.

## Срез 0 готов, когда на твоём iPhone
1. IPA ставится через ESign.
2. Вертикаль, пальцы попадают в кнопки.
3. Два бойца читаются по-разному.
4. Бой кончается KO или таймером и рестартится.
5. Нет вылета за минуту размена.
