# Tokyo Revengers Fighting — зафиксированные решения

Статус: опрос закрыт. v0.2 — 19.09.2026.
Код игры не меняется, пока нет команды «делай фазу 1».

## Платформа
- iPhone, только вертикаль, сенсор
- Сборка: unsigned IPA
- Подпись и установка: ESign
- Стек: SpriteKit (каркас в репо оставляем)
- Репозиторий: sascov5-eng/Tokyo-revengers-fighting
- Документы: `/docs`
- Сеть: онлайн не делаем

## Геймдизайн
- Вселенная: Tokyo Revengers
- Жанр: 2D-файтинг как Java-мод Naruto 2D Fighting
- Ростер: только Такемичи и Майки, пока не скажешь иначе
- Режим: игрок против CPU
- Меню: выбор, кем играешь; второй всегда CPU
- Победа: HP + таймер 99 сек
- Движение: только влево–вправо
- Блок: отдельная кнопка, удержание
- UI: русский; имена Такемичи / Майки
- Арт: боковые спрайты как в Java-моде
- Насилие: удары + кровь, оружия нет
- Звук: музыка, голос на ударах, сами удары; тумблер в настройках
- Источник арта: собираю и/или ищу в сети в стиле мода; ты правишь
